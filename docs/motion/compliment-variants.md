# Compliment variants

Eight original paired Vietnamese/English greetings cover everyday joy, personal pace, new possibilities, small pleasures, being heard, self-care, freedom and fresh beginnings. Copy offers appreciation without inferring personality, destiny or attributes from a name.

Each submitted name or anonymous entry chooses a new allowlisted variant, excluding the immediately previous choice. Replay keeps the current variant. Language changes translate the same variant. Personalized links preserve it through the allowlisted `wish` query parameter; unknown values are ignored. Older links remain compatible. Names are rendered as ordinary React text, not interpreted as prompts.

A2UI `componentSpec.props.data.compliment` carries `{id,body,signoff}`. These are authored variants selected locally, not falsely represented as new Groq-generated prose. No AI request or analytics field is added. The selected identifier is not derived from personal information and is never sent to the analytics collector.

The existing letter now pops in with 42 confetti pieces along the edges. Effects end and particles unmount after 3.2 seconds. The text is never replaced with a duplicate generic compliment. Reduced motion renders a static letter. Effects do not capture pointer input or change heading focus.
